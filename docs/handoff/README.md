# 음성 인식 플래시카드 평가 시스템 — 배포 가이드 (v3, 환경설정 탭 방식)

> v2에서 한 걸음 더 단순화했습니다. 스크립트를 스프레드시트에 **종속(컨테이너 바인딩)**시켜
> `SHEET_ID`를 등록할 필요 자체를 없앴고, `MIC_PAGE_URL` 등 설정값은 스크립트 속성이 아니라
> 스프레드시트의 **"환경설정" 탭**에 넣어 코드 수정 없이 시트에서 바로 바꿀 수 있게 했습니다.

## 폴더 구성
```
gas-app/     → Apps Script 프로젝트 (스프레드시트에 종속)
mic-page/    → GitHub Pages 정적 페이지 (마이크·음성인식 담당)
```

## 1단계. 스프레드시트 준비
탭 4개 구성:

- **환경설정**: `key | value` — 아래 두 줄을 미리 입력해두세요 (값은 3단계 이후 채움)
  | key | value |
  |---|---|
  | MIC_PAGE_URL | (3단계 완료 후 입력) |
  | MIC_PAGE_ORIGIN | (3단계 완료 후 입력) |
  | BRAND_TEXT | *(선택)* 상단 브랜드 문구. 비우면 "Flashcard Voice Game System" |
  | APP_TITLE | *(선택)* 카드 제목·브라우저 탭 제목·마이크 팝업 탭 제목. 비우면 "Flashcard Voice Game" |
  | APP_SUBTITLE | *(선택)* 카드 부제. 비우면 "화면에 나온 단어를 정확히 발음하면 자동으로 채점됩니다." |
- **학생명부**: `학년 | 반 | id(학번) | name(이름)`
- **데이터**: `question | answers(쉼표구분) | timeLimit(초, 선택) | unit(선택) | lang(선택, 예: ko-KR/en-US, 기본값 ko-KR)`
- **기록**: `일시 | 학번 | 이름 | 모드 | 점수 | 맞은문항수 | 틀린문항수 | 출제문항수 | 틀린문제들 | 소요시간(초) | 단원` (헤더만 입력)

## 2단계. Apps Script 만들기 (컨테이너 바인딩 — 중요)
1. **1단계 스프레드시트를 연 상태에서** 메뉴 `확장 프로그램 → Apps Script` 클릭
   (script.google.com에서 새 프로젝트를 만드는 게 아닙니다 — 반드시 시트 안에서 열어야 `getActiveSpreadsheet()`가 이 시트를 가리킵니다)
2. 기본 생성된 `Code.gs`에 `gas-app/Code.gs` 내용 덮어쓰기
3. `+` 버튼으로 HTML 파일 3개 생성: `Index`, `Stylesheet`, `JavaScript` → 각각 내용 붙여넣기
4. 배포 → 새 배포 → 웹 앱
   - 실행 계정: **나**
   - 액세스 권한: **Anyone** (로그인 절차 없이 누구나 접속 가능)
5. 배포 URL을 학생들에게 공유 (아직 마이크 페이지 주소가 없어도 일단 배포는 가능)

## 3단계. 마이크 페이지 GitHub Pages 배포 (`mic-page`, 변경 없음)
1. GitHub 저장소 생성 (예: `voice-flashcard-mic`)
2. `mic-page/index.html`을 저장소 루트에 업로드
3. Settings → Pages → Source를 `main` / `/ (root)`로 설정
4. 생성된 `https://<계정>.github.io/voice-flashcard-mic/` 주소를 **스프레드시트의 "환경설정" 탭**에 입력:
   - `MIC_PAGE_URL` = `https://<계정>.github.io/voice-flashcard-mic/`
   - `MIC_PAGE_ORIGIN` = `https://<계정>.github.io`
5. **코드 수정이나 재배포 없이** 시트 저장만으로 바로 반영됩니다 (새로고침 시 적용)

## 4단계. 파일럿 테스트 (필수)
- Android Chrome / iPad Safari / iPhone Safari 각 1대 이상에서 접속 → 이름 선택 → 문항수/모드 선택 → 팝업 → 마이크 권한 허용 → 평가 → 결과 저장까지 확인
- 환경설정 탭 값을 비워두거나 잘못 넣었을 때 안내 메시지가 뜨는지도 확인 (JavaScript.html에 반영됨)

## 향후 확장 시 참고
"환경설정" 탭은 key-value 구조라 나중에 Deepgram API 키 등 새 설정이 필요해져도 **탭에 행만 추가**하면 되고, `getConfig_()`가 자동으로 읽어들입니다. 코드 수정이 필요 없습니다.

## 참고 — 영어 단어 등 다른 언어 문항
데이터 탭의 `lang` 열에 `en-US`를 넣으면 그 문항만 영어로 인식하도록 음성인식 언어가 전환됩니다. 비워두면 기본값 `ko-KR`로 인식합니다. 한 시트 안에서 문항별로 언어를 섞어 써도 됩니다.

## 참고 — 학년/반/이름 3단 드롭다운
학생명부 탭에 학년·반 열을 추가해, 학생이 접속 시 학년→반→이름 순서로 좁혀가며 선택합니다. 반 인원이 아무리 많아도 첫 드롭다운이 길어지지 않습니다.

## 참고 — 단원별 출제 필터
데이터 탭의 `unit` 열에 값을 채워두면, 학생 화면에 "단원 선택" 드롭다운(기본값 "전체")이 자동으로 나타납니다. `unit` 열을 하나도 안 채웠다면 드롭다운 자체가 안 보이고 평소처럼 전체 문항에서 출제됩니다 — 별도 설정 없이 자동 전환됩니다.

## 참고 — 시간측정 모드 TOP 3
시간측정 모드로 응시하면, 결과 화면에 **같은 단원 + 같은 문항 수**로 응시한 기록 중 가장 빠른 3건의 시간이 자동으로 표시됩니다 (이름은 표시되지 않음). 본인 기록이 그 안에 들면 강조 표시됩니다. 문항 수가 다르면 비교 자체가 불공정하므로 순위 대상에서 제외됩니다 — 순위표가 잘 채워지게 하려면 학급마다 문항 수를 통일해서 풀게 하는 걸 권장합니다. `기록` 탭의 `단원`·`출제문항수` 열 데이터를 기준으로 계산되므로, 헤더 순서를 바꾸지 마세요.
